# A Adventure 0.1.1v

Simple Android exploration application.

Current target:
- Large open-world style map
- Explore from one side toward the other
- Trees and small rocks
- Camera-style map exploration by dragging the screen
- GitHub Actions APK build

## GitHub Actions
Upload this project to a GitHub repository, then open **Actions → Build A Adventure 0.1.1v APK → Run workflow**.

The generated APK is uploaded under the workflow run's **Artifacts** section.
